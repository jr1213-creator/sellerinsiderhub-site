Your assignment: explain what September sales actually contributed.

A fictional business sells desk pads and canvas pouches through its website and a marketplace. The owner wants to know which channel and product combinations deserve investigation. The export has duplicate records, cancelled orders, inconsistent channel labels, refunds and one missing item cost.

Your deliverable is a checked account of this sample month. It must show net sales and the amount remaining after item costs, transaction fees and seller-paid shipping. We call that amount operational contribution throughout the exercise. It excludes advertising, overhead, owner labor and taxes, so it does not establish the business’s final profit.

By the end, you should be able to explain why an order can legitimately appear twice, why an unknown cost cannot become zero, and why a higher contribution rate does not prove that moving sales to another channel will improve the business.

  1. Save the original file and define what each row represents.
  2. Produce a cleaning log with the IDs and reasons for every exclusion or correction.
  3. Reconcile the cleaned rows and monetary totals against the answer key.
  4. Build one chart from the checked summary.
  5. Write a memo that separates observed amounts, possible explanations and the next information needed.

02 / Read the data contract

One row is an event, not necessarily a new order.

The CSV contains September 2026 events in USD. Dates use YYYY-MM-DD. Amounts are event totals, not per-unit amounts. A sale and a later refund can share an order ID but must have different event IDs. There is one sale event per completed order in this small sample; a real multi-item export may contain several sale lines per order.

Refund policy for this fictional scenario: none of the refunded goods creates a restock credit, fee reversal or recovered shipping cost. The zeros on refund-event cost fields mean there is no additional cost or reversal on those events. Costs from the original sale remain. A refund is not evidence that inventory became sellable again.

Before adapting this to your store, establish your export’s actual sign conventions, tax treatment, shipping revenue, line-item structure, refund timing and inventory adjustments. The supplied metric definitions apply to this exercise, not automatically to every seller platform.

Prompt 1: inspect the source

Inspect the attached sales-events-dirty.csv without modifying it.

This is fictional September 2026 event-level sales data in USD. A row is a sale or refund event. event_id is the event key; order_id may legitimately repeat. Amounts are totals for each event, not unit prices. Refund amounts are positive deductions. Refund events do not reverse item costs, fees or shipping in this exercise.

Do not fill blanks, delete records or recommend business changes yet. Show the relevant event IDs and source row numbers. If code execution is unavailable, say so rather than claiming the calculations ran.

04 / Make the cleaning decisions explicit

Remove duplicate events. Keep the refund history.

Save the original file unchanged. Work on a copy. Here, both repeated event IDs are exact copies, so keeping their first occurrence is justified. If a repeated ID had different amounts or dates, the correct next step would be to resolve the conflict, not arbitrarily keep the newest row.

Prompt 2: apply the approved rules

Create a separate working dataset and a cleaning log. Apply these rules in order:

1. Remove only later exact duplicates of event_id, after confirming all fields match. Stop and report any conflicting duplicate.
2. Exclude cancelled orders. In this exercise they are uncompleted drafts, with no actual costs.
3. Trim channel whitespace and lowercase the supplied labels. Valid results are website and marketplace. Report any other value.
4. Retain every legitimate sale and refund event. Never deduplicate by order_id.
5. Keep the missing cogs_usd value unknown. Do not infer it from another sale or fill it with zero.
6. Compute net_sales_usd = gross_sales_usd - discounts_usd - refunds_usd.
7. Contribution requires known item cost, fees and shipping. Mark affected contribution results unavailable until the missing cost is confirmed. Do not sum partial contributions and label them complete.

Return row counts at each stage, the excluded event IDs, changes to channel labels, remaining missing values and net sales. Export a cleaning log and the working file. Show the calculation method or code.

Expect 27 raw rows → 25 unique events → 23 retained events. Remove the later copies of S003 and R002, and exclude cancelled events S021 and S022. Keep refund events R001, R002 and R003. Channel spelling changes affect S005, S008 and S017.

You can report net sales before resolving the missing item cost because net sales does not use that field. You cannot report a complete contribution total. Counting the blank as zero would overstate final contribution by $12 once the confirmation below is applied.

Resolve the unknown using a supplied record

Download owner-confirmation.csv and attach it to the same conversation. It is a fictional owner’s confirmation tied to S015, dated October 1, 2026. It documents an item cost of $12.00 for that event and the exercise’s no-reversal refund rule.

Prompt 3: apply a traceable correction

Use owner-confirmation.csv to resolve the missing cost by event_id and field_name. Confirm that the key matches exactly one retained event. Record the old blank, the confirmed value, confirmation date and source in the cleaning log. Do not change any other cost.

Now calculate contribution_usd = net_sales_usd - cogs_usd - payment_fees_usd - shipping_cost_usd. Return totals by channel and by channel plus product_sku, with net sales and contribution. Calculate each contribution rate as grouped contribution divided by grouped net sales; do not average row percentages.

Count distinct completed sale order IDs separately from retained event rows. State the refund policy and the omitted costs. Export the cleaned CSV, summary table and calculation code.

Checkpoint: the corrected file still has 23 rows. A lookup must not multiply rows. In this sample, there are 20 completed orders and 33 units sold before returns. Refund-event quantity is zero, so this dataset cannot tell you net units kept by customers.

05 / Check the arithmetic yourself

Rebuild the totals in Excel or Google Sheets.

Download your cleaned result before closing the conversation. OpenAI’s table documentation shows a download control for CSV output. If the answer does not include a usable file, ask for the CSV explicitly and check its contents after saving.

In desktop Excel, use Data → From Text/CSV and review the comma-separated preview. In Google Sheets, use File → Import → Upload, select the file and import into a new spreadsheet or new sheet. Call the working sheet Clean. Preserve IDs as text and confirm monetary columns contain numeric values. A format that displays two decimals does not convert text into a number.

Import instructions: Microsoft CSV import and Google Sheets file import.

Keep columns A–O in the original order. Put net_sales_usd in P1, contribution_usd in Q1 and cost_status in R1. Enter these formulas in row 2 and fill through row 24, the last of the 23 retained events. These English-language formulas use commas; regional settings may require semicolons.

Spreadsheet formulas for this exercise

Clean!P2 — net sales
=J2-K2-L2

Clean!Q2 — contribution, preserving an unknown cost
=IF(ISNUMBER(M2),P2-M2-N2-O2,"")

Clean!R2 — cost status
=IF(ISNUMBER(M2),"Complete","Cost missing")

Summary: net sales
=SUM(Clean!P2:P24)

Summary: complete contribution only
=IF(COUNT(Clean!M2:M24)<ROWS(Clean!M2:M24),"Cost missing",SUM(Clean!Q2:Q24))

Website net sales
=SUMIFS(Clean!P2:P24,Clean!H2:H24,"website")

Website desk-pad contribution, after all costs are confirmed
=SUMIFS(Clean!Q2:Q24,Clean!H2:H24,"website",Clean!F2:F24,"PAD")

Raw event-ID occurrence counter: put in a spare column, fill rows 2–28
=COUNTIFS($A$2:A2,A2)

The last formula marks a later occurrence with 2, but you still need to compare its full row before deleting it. The contribution guard checks the one known missing-input risk in this exercise. For a real export, validate every required monetary field rather than assuming fees and shipping are complete.

For a visual cross-check, create a pivot table from the corrected Clean!A1:R24 range. Put channel and product_sku in Rows. Put net_sales_usd and contribution_usd in Values, summarized by SUM, not COUNT. Confirm that every group and the grand total agree with the formula summary. Calculate rates from grouped totals outside the pivot.

Function references: Microsoft SUMIFS, Google SUMIFS and Google pivot tables.

Test the guard: in a disposable copy of the supplied workbook, clear Clean!M16, the S015 cost. Review must show “Cost missing” for total contribution. Enter a numeric zero and the total becomes $252.90. Enter 24 and it becomes $228.90. Restore the confirmed 12 to recover $240.90. This demonstrates that unknown, zero and changed values behave differently.

07 / Turn checked figures into an appropriate decision

Build one useful chart, then write a memo that respects the evidence.

A horizontal bar chart makes four contribution amounts easy to compare. Start its value axis at zero, show USD and label each bar. Do not combine percentages and dollars on one unlabeled scale or use a decorative chart that hides the group names.

Prompt 4: chart and decision memo

Use the reconciled channel-and-product summary only.

Create a horizontal bar chart of operational contribution in USD for all four groups. Start the value axis at zero and label each amount. Title it September contribution by channel and product. Mark the data as fictional and list the costs excluded from the metric. Export the chart and its underlying table.

Write a 150–200-word owner memo with:
- Two observations tied to exact checked figures.
- One plausible explanation clearly labeled as a hypothesis.
- One specific next investigation, including the missing data needed.
- A decision we should not make from this sample alone.

Do not claim causation, forecast growth, calculate conversion without visitor data, or describe contribution as final business profit. There is only one small synthetic month and no advertising, overhead, labor or tax data.

Worked memo

September’s fictional sales produced $702 in net sales and $240.90 in operational contribution after item costs, transaction fees and seller-paid shipping. The website contributed $164 on $382 in net sales. The marketplace contributed $76.90 on $320. Website desk pads were the largest contribution group at $114.24; marketplace pouches were the smallest at $29.48.

A possible explanation for the channel difference is the mix of recorded fees and refunds. Marketplace fees total $48.10 compared with $15 on the website, and marketplace refunds total $50 compared with $18. These are observations from this sample, not proof that channel choice caused the difference.

Next, reconcile the three refunds to their documented reasons and collect channel-specific advertising costs and comparable prior months. That would help distinguish an unusual refund month from a recurring cost problem. I would not close the marketplace or move advertising budget based on this file alone. The sample contains only 20 completed orders and excludes overhead, advertising, owner labor and taxes. It also lacks visitor data, so it cannot establish which channel converts better.

Common ChatGPT and Excel questions

Can AI analyze my Excel spreadsheet?

ChatGPT supports common spreadsheet formats, including XLSX and CSV, when the available account tools permit. Give it the file, a field dictionary and the decision you need to support. Confirm which rows and sheets it actually used. This lab starts with CSV because the row structure and calculation inputs are easy to inspect.

Which ChatGPT model is best for Excel?

There is no comparative model test in this lesson. Start with a model or mode that can access the required analysis tools on your account. Assess its output against the same control totals, refund case and missing-cost test. A model name or higher-priced plan does not verify an answer.

What are good ChatGPT prompts for Excel data analysis?

Use the four staged prompts above: inspect, apply approved cleaning rules, resolve the documented correction, then communicate checked results. For your own file, replace the field definitions, period, valid categories and exclusions. Those details carry more information than asking ChatGPT to “act like an expert.”

Do I need an API key or a third-party Excel extension?

No for this upload-and-verify workflow. The optional official OpenAI add-in is a separate route with its own installation and plan usage terms. Older guides may describe third-party products or an earlier interface; follow the current vendor instructions linked above.

Can this predict next month’s sales?

This exercise does not support that claim. It contains one small fictional month and no traffic, promotion or inventory history. It teaches you to establish reliable descriptive numbers first and identify the additional evidence a forecasting project would require.
