01 / Make something worth receiving

Build a two-page planning sheet in Canva.

Our fictional shop is Paper Meadow. It sells an undated desk pad, but the free resource is useful without buying one. The PDF has a blank worksheet on page one and a completed example on page two. The goal is practical: help someone choose three priorities and identify the first action for each.

  1. Create the document. In Canva, start a blank document or a simple document design. Choose an ordinary page size your audience prints, such as US Letter or A4. Use a clear heading, generous writing space, and a readable body font. A plain worksheet is enough.
  2. Add the content below. Keep page one blank where the reader will write. Duplicate the layout for page two and enter the completed example. Put “Illustrative example” on that page so it cannot be mistaken for a customer result.
  3. Export. Use Share → Download → PDF Standard for the screen download. Canva also offers PDF Print when print quality is the priority. Select only the intended pages. Name the file paper-meadow-weekly-planning-v1.pdf.
  4. Check the actual export. Open the downloaded PDF on a phone and desktop. Print a page if you describe it as printable. Check that the title, instructions, writing areas, and second page survived the export.

Export reference: Canva PDF maker; format differences and paid export options: Canva file types. The worksheet layout and copy are original examples.

02 / Give the file a dependable home

Upload the PDF once and use a file link in the email.

In MailerLite, open File manager → Upload and choose the PDF. Its documented file limit is 10 MB. Use a versioned filename so you can recognize the correct resource later. When editing email 1, highlight “Download the weekly planning sheet,” open the link control, choose Insert File, and select this file. MailerLite supports file links in its Drag & drop and Simple email editors.

Why a link matters: the recipient should be able to open the resource from the delivered message without access to your Canva account. Send a preview to yourself, click the link, and try it in a signed-out browser. Keep the file available after sending; replacing an email draft does not repair a link inside a message already delivered.

File upload and editor controls: MailerLite’s PDF guide. The access and version checks are our implementation recommendations.

03 / Prepare the sender

Make the address in the inbox match the business on the page.

Use a sender name a subscriber will recognize, such as Paper Meadow, and a reply address someone checks. Complete the account’s approval and verification prompts. For a custom sending domain, open Account settings → Domains → Add sending domain. Follow automatic authentication if your DNS provider is supported, or enter the exact records MailerLite generates in your DNS host. Return to MailerLite and confirm the domain status is authenticated.

Do not copy another tutorial’s DNS values: the account supplies the records for your domain. If your domain already has an SPF record, follow the provider’s instructions for merging it rather than adding a competing one. Keep the required sender details and working unsubscribe footer in every email.

Current requirements and controls: MailerLite domain authentication and authentication troubleshooting. Domain ownership, account review, and DNS propagation can delay readiness; do not promise delivery until the test passes.

04 / Connect the promise to the right group

Create one group and a focused signup page.

In Subscribers → Groups, create Weekly planning sheet. This group identifies the specific resource request. Avoid a generic “All subscribers” trigger that might enroll unrelated customers. MailerLite’s group guide explains the group controls.

  1. Open Sites → Landing pages → New site. Name the page Weekly planning sheet signup and continue.
  2. Select Weekly planning sheet as its subscriber group. Choose Start from scratch.
  3. Add a heading, a preview of the worksheet, short explanatory text, and a signup form. Keep email as the required field. Add a privacy-policy link and accurate business identity.
  4. Use the copy below. Check the mobile view, save, and publish using the available MailerLite URL. Open the published URL while signed out.

These controls refer to the current landing-page builder, not the older legacy-editor tutorial. Page changes must be published before visitors can see them.

Keep confirmation and delivery separate.

In the page or form overview, keep Double opt-in enabled. Review its confirmation message and thank-you page. The free plan does not allow editing the confirmation email; you can use its standard message. The confirmation email confirms the address. Your automation email delivers the PDF. Do not also add a second delivery automation for the same signup.

A new unconfirmed address needs to confirm before receiving this marketing sequence. An already active address does not receive the same confirmation request. That distinction is why tests need fresh addresses. For several signup locations offering the same resource, connect them to this one group rather than building competing form-triggered journeys.

What an existing subscriber should expect

An active subscriber who is new to this resource group can become eligible for its group-triggered sequence. Someone already in the group has not newly joined it simply by submitting the form again. Do not enable indefinite repeat entry just to repair one missed file. Check the record, supply the requested resource once when appropriate, and keep the original subscription preferences intact.

Keep it working after launch.

Once a week, open the file and product links, inspect failed workflow activity, and check the sender inbox. Before changing a price or resource, update the source file and the relevant email together. Give each version a date and keep the old file available for recipients of earlier messages.

Budget sends across the entire account. For example, 100 new subscribers completing three emails use 300 automation sends. Four broadcasts to 200 recipients use 800 more, for a planning total of 1,100 before other messages and tests. This is arithmetic for an illustrative account, not a forecast. The separate 250-active-subscriber limit can be reached before the email allowance.

Judge usefulness with evidence you can inspect: confirmed requests, successful delivery, meaningful replies, resource access when measurable, and purchases attributable through your actual setup. The workflow creates a reliable response to interest; it does not create visitors by itself. If nobody sees the signup page, changing the delay from two days to one will not solve that problem.
