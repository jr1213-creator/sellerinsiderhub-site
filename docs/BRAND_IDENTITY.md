# Seller Insider Hub identity

The approved identity is the boxed S beside two lines of lettering: bold uppercase **SELLER**, with **Insider Hub** below. The selected version uses the closely spaced, heavier SELLER lettering. Preserve these outlined letterforms and the boxed-S silhouette when creating new placements.

## Master artwork

All production assets live in `assets/brand/`. The SVG master uses real outline paths, without an embedded bitmap or a downloadable font dependency. It was traced from the owner's approved artwork and flattened to one consistent color.

- Forest green: `#11402d`
- Supporting ivory: `#f8f7f3`
- Full logo viewBox: `0 0 1263 371`
- Standalone boxed S viewBox: `0 0 363 363`

Use `seller-insider-hub-logo.svg` on light backgrounds and `seller-insider-hub-logo-white.svg` on dark backgrounds. `seller-insider-hub-logo-black.svg` is the monochrome alternative. Preserve the aspect ratio and built-in safety padding. Use the full logo in page headers and footers; use the boxed S where the full name would become too small to read.

## Browser and device icons

`favicon.svg`, the 16/32/48-pixel PNGs, and the multi-resolution ICO use the boxed S with a white interior so the S stays clear in dark browser tabs. `apple-touch-icon.png` is an opaque 180-pixel image. Additional 192- and 512-pixel icons are available.

`scripts/brand_components.py` generates shared brand and icon markup. Its content hash versions the icon URLs. The build also maintains `/favicon.ico`, `/apple-touch-icon.png`, and the former `/assets/img/favicon.svg` endpoint. Keep these aliases in the build; do not reintroduce the old `si.` generator.

## Site integration

- Public headers, footers, icon metadata, social previews, and organization metadata are generated by `scripts/build_site.py`.
- The homepage publication note uses the standalone mark through `scripts/editorial_components.py`.
- Investor-room branding is generated by `scripts/investor_components.py`; the sign-in page lives in `netlify/lib/investor-auth.mjs`.
- Header sizing is responsive in `site-assets/hub.css` and `site-assets/investor.css`. Keep navigation and search usable at 320-pixel viewport width.
- The social card is `seller-insider-hub-social.png`, with its SVG source alongside it, at 1200 × 630 pixels.

Review the SVG in a browser after changing export tooling. In particular, serialize integer path coordinates without a trailing decimal point; some raster renderers accept forms that browser SVG parsers reject.
